{% if signed_in and approved %}

Windows setup

  1. Connect to office Wi-Fi or the office network cable.
  2. Close files on existing network drives.
  3. Download and review the setup helper.
  4. After Axon approves the signed helper for rollout, right-click it and choose Run with PowerShell.
  5. The helper shows current mappings and starts with a check-only choice. Type MAP only when ready to continue.
  6. Enter your personal NAS password when asked. Microsoft sign-in does not supply the NAS password.
  7. Matching mappings are kept. A conflicting drive requires explicit replacement confirmation and records a recovery path. Unrelated drives stay connected.
  8. Open File Explorer → This PC.
Download my Windows setup

Current helpers are for commissioning until signing and real-device tests are complete.

Mac setup

  1. Connect to the office network.
  2. Download the Mac helper and run it using the Terminal instructions above.
  3. Review the current SMB connections shown locally.
  4. Matching connections are kept. The helper does not eject old volumes. Close their files and eject only the old company volume you intend to replace.
  5. Confirm CONNECT to open your approved folders in Finder.
  6. Enter your personal NAS login in Finder. Add mounted folders to the Finder sidebar.
Download my Mac setup

Mac uses Finder locations rather than Windows drive letters.
