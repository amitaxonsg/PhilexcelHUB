Overview

Synology DS223, two 2 TB WD Red Plus disks, 24-port gigabit switch, APC UPS, office LAN shares and dedicated Microsoft 365 Company Hub sync. Board SharePoint is excluded. Axon IT supports remotely through newly configured secure Tailscale access; no existing VPN or fixed public IP required.

RAID vs Basic: Two independent Basic volumes give about 4 TB combined raw capacity across separate volumes, but no automatic disk-failure protection. RAID 1 mirrors data and gives roughly 2 TB usable. No RAID arrangement replaces an independent tested backup. Get explicit approval of storage design before setup.

SMB is Windows network file sharing. It enables paths such as \\PHILEXCEL-NAS\Marketing to appear as mapped drives in File Explorer.

Understanding the design — Why we are building Philexcel Hub

Not an ordinary NAS: this is a managed local-plus-cloud document system with centralized permissions, staff self-service administration, automation, support, tested recovery and future AI readiness.

1. Local work through SMB

Employees use personal NAS accounts to access assigned Windows network drives over the office LAN. SMB means Server Message Block, the file sharing protocol used by Windows. This removes dependence on shared folders hosted on individual staff PCs.

2. Basic volumes instead of RAID 1 mirroring

The proposed two independent 2 TB Basic volumes provide about 4 TB total raw capacity across two volumes. They are NOT one large 4 TB drive. RAID 1 would provide about 2 TB usable but could withstand failure of one disk. Basic provides no redundancy, so separate versioned backup, monitoring, an actual restore test and explicit business risk approval are mandatory. Cloud Sync is a copy that can also propagate deletions and corruption: it is NOT an independent backup.

3. Local NAS and online Company Hub

Approved local department files sync through Synology Cloud Sync to separate Microsoft 365 SharePoint Company Hub libraries using hub@philexcel.com as the sync identity. Offsite employees use their OWN Microsoft 365 sign-ins to browse and edit cloud files. The NAS and Microsoft 365 accounts remain independent; their permissions must each be set and verified. The separate Board SharePoint project is excluded.

4. How updates and conflicts work

First pilot NAS-to-cloud upload. To permit cloud changes to return to NAS, configure and verify bidirectional sync in a TEST library. Measure sync delay and test two people editing, file deletions, versioning and recovery before enabling two-way production. Files opened over SMB do not automatically co-author with someone using SharePoint.

5. Dashboards and responsibility

Axon IT maintains NAS, backups, monitoring and secure remote support. Philexcel Admin manages NAS employees, approved departments, Read/Write versus Read-only permissions and audit. Department users have individual password-protected landing pages. These production controls require a server-side authenticated application: the public GitHub Pages project is a planning preview only.

6. Automation, growth and Phase 2

PowerShell on each Windows PC previews and maps only approved shares, checks connectivity and collects UAT evidence; use verified DSM/Synology tools for storage and NAS administration. As Philexcel grows, add employee groups, SharePoint libraries and supported cloud capacity. Physical NAS growth beyond two bays needs larger disks or new hardware. Spencer deployment sequence — Phase 1

  1. Check model, DSM build, disks, UPS, router, cabling and switch; measure negotiated LAN speed.
  2. Record hostname, NAS reserved private IP, subnet, gateway, DNS and serials in the private register.
  3. Approve Basic versus RAID storage and independent versioned backup before creating volumes.
  4. Install/update DSM and secure administrator, MFA, HTTPS, firewall, alerts and recovery account.
  5. Create six departmental SMB shares and CompanyShared, each with separate NAS security groups.
  6. Verify staff spellings, assign initial Read/Write access only within authorized departments.
  7. Test authorized and unauthorized access; document group memberships and direct permission exceptions.
  8. Back up old Z: on Admin PC, migrate data, verify samples/counts and obtain signoff before switching.
  9. Map drives with PowerShell on PCs only after access and drive-letter conflicts are checked.
  10. Prepare hub@philexcel.com license and separate SharePoint Company Hub libraries with cloud permissions.
  11. Pilot NAS-to-cloud Cloud Sync. Enable two-way only after cloud-edit, concurrent-edit, deletion and version-restore tests.
  12. Configure Tailscale secure Axon-only remote support; do not publish DSM/SSH/SMB on the internet.
  13. Complete independent backup/restore and UPS tests. Enable cloud-sync and hardware alerts.
  14. Deploy three role-specific password-protected dashboards: Axon IT, Philexcel Admin, and department landing pages.
