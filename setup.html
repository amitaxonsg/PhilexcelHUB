Overview

Synology DS223, two 2 TB WD Red Plus disks, 24-port gigabit switch, APC UPS, office LAN shares and dedicated Microsoft 365 Company Hub sync. Board SharePoint is excluded. Axon IT supports remotely through newly configured secure Tailscale access; no existing VPN or fixed public IP required.

RAID vs Basic: Two independent Basic volumes give about 4 TB combined raw capacity across separate volumes, but no automatic disk-failure protection. RAID 1 mirrors data and gives roughly 2 TB usable. No RAID arrangement replaces an independent tested backup. Get explicit approval of storage design before setup.

SMB is Windows network file sharing. It enables paths such as \\PHILEXCEL-NAS\Marketing to appear as mapped drives in File Explorer.

Spencer deployment sequence — Phase 1

  1. Check model, DSM build, disks, UPS, router, cabling and switch; measure negotiated LAN speed.
  2. Record hostname, NAS reserved private IP, subnet, gateway, DNS and serials in the private register.
  3. Approve Basic versus RAID storage and independent versioned backup before creating volumes.
  4. Install/update DSM and secure administrator, MFA, HTTPS, firewall, alerts and recovery account.
  5. Create six departmental SMB shares and CompanyShared, each with separate NAS security groups.
  6. Verify staff spellings, assign initial Read/Write access only within authorized departments.
  7. Test authorized and unauthorized access; document group memberships and direct permission exceptions.
  8. Back up old Z: on Admin PC, migrate data, verify samples/counts and obtain signoff before switching.
  9. Map drives with PowerShell on PCs only after access and drive-letter conflicts are checked.
  10. Prepare hub@philexcel.com license and separate SharePoint Company Hub libraries with cloud permissions.
  11. Pilot NAS-to-cloud Cloud Sync. Enable two-way only after cloud-edit, concurrent-edit, deletion and version-restore tests.
  12. Configure Tailscale secure Axon-only remote support; do not publish DSM/SSH/SMB on the internet.
  13. Complete independent backup/restore and UPS tests. Enable cloud-sync and hardware alerts.
  14. Deploy three role-specific password-protected dashboards: Axon IT, Philexcel Admin, and department landing pages.
